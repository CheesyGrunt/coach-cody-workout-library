Tell me how you want to be credited — full name, first name, club, or nothing at all. If you'd rather stay anonymous, say so and it goes in unattributed. Your call, every time.

Helpful, but not required

Send it either way. These just save me a round of emails asking:

  • Course — short course yards, short course meters, or long course meters. This one matters most. The same set is a different workout in a 50m pool.
  • Group or ability level — 11-12s, senior group, whoever it was written for.
  • Total distance — if you know it. I can add it up if you don't.
  • How it actually ran — what worked, what you'd change, where kids fell off the interval. This is the good stuff and almost nobody sends it.
  • How to credit you — name, club, or anonymous.
